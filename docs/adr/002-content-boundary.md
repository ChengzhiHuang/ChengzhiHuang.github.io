# ADR 002：文章与私有归档隔离

状态：接受。

原文、原图、来源映射、待审稿与对照材料保存在站点仓库之外。站点内容集合只加载 `src/content/posts/*/index.md`，不访问私有目录。预览待审文章采用独立的本地副本，不向正式内容目录注入草稿。

正文、图片采用逐篇目录。首页、分类、搜索、RSS、站点地图通过同一 `getIndex` 读取验证后的元数据。Markdown 保留作者措辞和章节顺序，结构调整需要作者决策。

验证：拒绝源文件符号链接、越界导入与图片引用、浏览器 Node API、远程图片、重复稳定标识和缺失元信息。构建后检查真实 HTML 引用及摘要数据一致性。人工审阅绑定整篇目录哈希，图片需逐张复核。

脱敏名单同样是私有材料。原始人员姓名、业务符号和组件映射不得写入本站检查器或测试夹具。项目专用扫描在私有审阅及导入工具中执行；本站保留通用路径、凭证、链接与素材规则，并以审阅哈希约束定稿。本站构建和 Harness 不读取私有名单。
