# ADR 003：可执行约束与验证证据

状态：接受。

参考分层工程约定，将设计边界落实为检查和失败用例。check、verify、package 按依赖顺序执行；任意必要步骤失败即停止，不能用跳过的检查宣称成功。

每次运行记录源码摘要、运行时版本、实际命令、退出码、耗时及证据位置。浏览器回归覆盖手机、平板和桌面，使用生产构建且屏蔽非 localhost 请求。打包先重新验证，再检查作者审阅哈希和执行期间源码未变化，输出压缩包及每个文件的 SHA-256。工具执行完成即退出。

证据保存在忽略目录，不进入静态产物。单测采用合成素材，站点工程可离开原始归档独立构建。哈希用于发现受审内容变化，不宣称是密码学身份签名；作者审阅事实仍需真实记录。
