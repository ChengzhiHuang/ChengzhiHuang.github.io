# ADR 004 — 公开系统二进制的精确例外

状态：接受。

作者确认 UIKitCore iOS 16.2 为公开 Apple 系统二进制，允许原样保留其中系统兼容逻辑里的公开产品 bundle ID。不得修改二进制字节，也不把此决定扩大到内部业务附件。

附件检查器仅对 SHA-256 为 `831c4ebb13a517de5771810fa00c82894df98549dde2406b8de9f4b01334a8ef` 的文件豁免产品 bundle ID 规则。其他敏感信息检查照常执行；文件变化后例外失效。正文或其他附件没有此豁免。

本决定不构成整篇文章审阅通过，更不构成发布授权。
