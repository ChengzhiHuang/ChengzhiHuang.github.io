# ADR 005 — Markdown 展示与附录阅读

状态：接受。

文章继续采用 Markdown。`> [!TLDR]` 引用块表示默认展开的摘要，保留列表和图片；标签不会成为目录标题。需要合并单元格的表格使用静态 HTML，保持语义与横向滚动。QoS 表格保持完整标识符，窄屏在表格内横向滚动，避免单词被拆行。

只有带 `annotated` 元信息的代码围栏解释成对的 `**加粗**` 与 `~~删除线~~`；先提取标记范围，再高亮原代码，最后在原范围应用样式。普通围栏不解释这些标记，注释星号串与未配对符号保留。复制操作保留所有代码字符，包括划线部分，仅去掉展示标记。代码批注不等于生成可直接执行的修改后程序。

Markdown 附件通过独立集合读取固定的文章附件目录，必须归属于已有文章。阅读地址为 `/posts/<slug>/attachments/<name>/`，原文件地址为 `/files/<slug>/<name>.md`。附录进入站点地图，文章列表、搜索及 RSS 不计为新文章。

附件 Markdown 使用带 BOM 的 UTF-8，兼容缺少 charset 的静态服务器；构建复制原字节，审阅哈希覆盖 BOM。读页复用站点样式、目录和代码工具，不引入浏览器 Markdown 解析器或外部资源。

UTF-8 源码和文本附件通过固定扩展名清单在构建时读取，生成保留文件扩展名的阅读地址。原文件不改编码或字节，避免源码下载发生变化；HTML 阅读页声明 UTF-8，并将源码作为转义文本输出，高亮模式下通过纯 CSS 伪元素显示不可选中的行号以确保复制内容与原字节严格一致。大于 256 Ki 个字符的文件使用普通代码块，以限制语法高亮的节点数量。校验拒绝非法 UTF-8、NUL 字节和与 Markdown 附录冲突的阅读地址。

外部 HTTP(S) 链接统一使用 `target="_blank"` 及 `rel="noopener noreferrer"`，保留已有 rel。Markdown 转换在解析原生 HTML 后处理链接，模板中的导航与页脚显式设置相同属性；构建产物再次核对。站内绝对地址、相对地址、锚点及邮件不受影响。合并表格同时支持 rowspan 与 colspan，不用空白单元格模拟合并，窄屏及宽表配合纯 CSS 边缘滚动阴影提示横向滚动。正文页在客户端渐进增强代码块语言顶栏、目录当前小节高亮与窄屏抽屉目录、章节锚点复制、从附录阅读页返回正文时的原位置恢复及大图查看器 `1:1` 原始尺寸切换。
