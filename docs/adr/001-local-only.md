# ADR 001：本地交付与禁止发布

状态：历史决策；本站发布范围已由 [ADR 006](006-reviewed-publication.md) 取代。私有资料隔离要求继续有效。

本工程服务个人博客整理，当前任务没有任何发布授权，作者审阅也不会改变这一点。工程仅初始化本地 Git，没有 remote；通过默认拒绝的 pre-push 钩子和架构检查阻止误操作。不得加入启用的 CI、Pages 或上传命令。开发和回归服务器只监听 127.0.0.1。

这些约束减少误操作，但不能代替人的权限判断；主动绕过本地钩子仍被禁止。未来若另有发布需求，应新建决策并获得独立授权，本工程不提供隐式开关。

验证：检查 remote 为空，hooksPath 正确，直接运行钩子确认退出码为 1；扫描工作流和 package scripts。
