# Harness boundary
These scripts run locally or in the authorized Pages workflow and must finish. Harness commands check, test, build and package; they never transmit content or invoke a push/deployment. Only the exact authorized repository may be configured as origin. Git writes are limited to local setup; the pre-push hook performs read-only validation. Evidence belongs under ignored .harness and is not a Pages artifact. Missing checks fail. Human review records bind the complete article directory by SHA-256; record only an actual explicit author approval. Audit every outgoing commit, including files deleted by a later commit.
